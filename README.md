# 本地智能图片库

一个面向 Windows 的离线优先图片库。应用以本机 Python 服务和浏览器界面运行：图片留在原目录，应用在本地建立 SQLite 索引、缩略图缓存和可选的语义向量索引。

> 当前交付形态是可运行的本机 MVP，不是 Windows 安装程序。模型权重不包含在源码包中。

## 功能一览

- 管理多个图片目录，递归扫描子目录并增量更新索引；扫描任务可暂停、继续和取消。
- 分页浏览和按目录、日期、标签、评分筛选；图片详情支持结果集内切换、滚轮缩放和平移。
- 按文件名、标签和手工录入的 OCR 文字搜索；安装本地 SigLIP2 模型后可做图片内容语义搜索，并调节最低相似度。
- 使用 dHash 提供近似重复候选，供人工检查。
- 图片详情提供裁剪、画笔、橡皮擦、马赛克、文字、旋转、翻转、撤销和 PNG 另存；原图不被覆盖。
- 移动、改名和移入回收站操作会先预览并确认；应用操作支持撤销。移除图库授权不会删除原文件。
- 导出 SQLite 数据库备份。

## 快速开始

### 环境

- Windows 10/11
- Python 3.10 或更高版本
- Pillow（用于读取图片信息、预览、缩略图和图片编辑）

### 安装和启动

```powershell
python -m pip install -r requirements.txt
```

然后双击 `run.bat`，或在项目目录运行：

```powershell
python server.py
```

应用会在本机启动并打开 `http://127.0.0.1:8765`。服务只监听 loopback 地址，不对局域网开放。

### 添加图片

在侧边栏选择“添加目录”，输入本机已有图片文件夹的完整路径。应用会递归扫描其子目录；扫描进度显示在页面顶部和任务中心。添加目录不会复制、移动或改写原始图片。

## 可选图片格式

基础图片解码依赖 Pillow。HEIC/HEIF 与相机 RAW 需要可选解码器：

```powershell
python -m pip install -r requirements-formats.txt
```

可扫描扩展名会依据已安装解码器显示。扩展名被识别不代表当前机器一定能生成该格式的预览。

## 可选 SigLIP2 语义搜索

1. 安装 `requirements-semantic.txt` 中的依赖；PyTorch 请按照机器的 CUDA 驱动或 CPU 环境单独选择安装版本。
2. 从 [Hugging Face 的 SigLIP2 模型页](https://huggingface.co/google/siglip2-base-patch16-224) 下载模型文件。
3. 将完整模型文件放到项目 `.local-models/siglip2-base-patch16-224/`，至少应包含模型配置、权重、图像预处理器和 tokenizer 文件。源码包不会附带模型权重。
4. 启动应用，在“本机状态”中选择“建立语义索引”。

GPU 可用时模型使用 GPU 推理；否则尝试 CPU。语义向量保存在本机 SQLite 中。第一次加载模型和索引图片可能需要较长时间。**SigLIP2 不是 OCR 引擎**：OCR 文本目前由用户手动粘贴或录入。

## 本机数据与隐私

默认数据目录为：

```text
%LOCALAPPDATA%\LocalImageLibrary
```

目录内包括 `catalog.db`、缩略图缓存和应用回收站。开发或测试时可以设置 `LOCAL_IMAGE_LIBRARY_DATA` 更改数据目录；服务端口可以通过 `LOCAL_IMAGE_LIBRARY_PORT` 设置。

图片内容、搜索文字和语义模型推理留在本机。应用不自动上传图片，也不调用第三方 AI API。数据库备份包含索引、目录授权、标签、OCR 文字和操作记录，但不含原始图片或可再生成的缩略图。

## 已知范围与限制

- 当前没有自动 OCR、人脸识别、视频索引、Qdrant 或专业 RAW 调色功能。
- 语义向量和精确相似度检索使用 SQLite；这是面向原型和中小型图库的实现，不是高规模 ANN 服务。
- 语义模型是可选的，且需要用户单独下载。未配置模型时，文件名、标签、OCR 和元数据搜索仍可使用。
- UI 使用浏览器文件系统 API 保存图片；若浏览器不支持，会提示输入本机保存路径。
- 本应用当前没有安装包、自动升级器或正式的跨平台支持承诺。

## 开发测试

在项目目录运行：

```powershell
python -m unittest discover -s tests -v
```

多数测试使用临时目录和合成图片。SigLIP2 集成测试需要本机模型与推理依赖，运行时间会明显更长。
