# 架构说明

## 系统概览

本项目以 Python 标准库 HTTP 服务、SQLite、静态 HTML/CSS/JavaScript 构成。本机浏览器和服务通过 `127.0.0.1` 通信；没有云端 API 或上传服务。

```text
浏览器 UI (index.html / style.css / app.js)
                │ HTTP + 本机随机令牌
                ▼
       server.py (ThreadingHTTPServer)
          ├── SQLite catalog.db
          ├── 缩略图与本机回收站
          └── 可选 semantic.py / SigLIP2
```

## 主要模块

### `server.py`

- 初始化数据库、图库目录授权和数据路径。
- 递归扫描图片并增量维护元数据、哈希与缩略图。
- 提供图片查询、详情、标签、评分、OCR 文本、语义索引和文件操作 API。
- 管理任务中心的扫描、语义索引、暂停/恢复/取消状态。
- 监听 `127.0.0.1`；修改类请求需带服务启动时产生的随机本机令牌。

### `semantic.py`

- 从 `.local-models/siglip2-base-patch16-224/` 或本机数据目录载入 SigLIP2。
- 编码图片与文本向量，并将推理放到可用的设备上。
- 模型和向量均保存在本机；具体设备及模型可用性通过健康/语义状态接口提供给 UI。

### 前端文件

- `index.html` 定义图库、搜索、详情、设置、任务和确认对话框。
- `app.js` 管理查询、页面状态、结果集导航、编辑器画布与各操作事件。
- `style.css` 定义暗色主界面和详情图片工具条、编辑浮层及响应式布局。

## 本机持久化

默认根目录为 `%LOCALAPPDATA%\LocalImageLibrary`，也可用 `LOCAL_IMAGE_LIBRARY_DATA` 改写。默认包含：

- `catalog.db`：图库授权、图片元数据、标签、OCR 文本、任务、操作记录和可选语义向量。
- `thumbnails/`：可再生缩略图缓存。
- `trash/`：应用移入回收站的文件。

SQLite 是当前唯一的持久化与向量存储。语义查询会扫描所选模型版本的向量并精确计算相似度；没有配置 Qdrant 或 ANN 向量数据库。

## 图片编辑

详情窗口先显示原图；首次进入编辑工具时将图像载入编辑画布。当前编辑使用基础图层、透明画笔/橡皮擦图层和透明文字图层：

- 裁剪同时裁切所有编辑图层。
- 旋转和翻转同时变换各图层。
- 马赛克在基础图层内执行像素化采样，可选添加色调。
- 撤销记录画布快照；保存时将图层合成为 PNG，另存至用户选择的位置。

除另存图片外，编辑过程不改写源文件。编辑快照会占用内存，历史栈最多保留 15 步或约 160 MiB 快照数据。

## 当前不包含

自动 OCR、人脸识别、Qdrant/ANN 向量库、视频索引、专业 RAW 调色、原生安装包与自动更新器。可解码 RAW/HEIC 的能力取决于可选依赖。
