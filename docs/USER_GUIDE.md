# 用户指南

## 启动和添加图库

1. 安装 Python 3.10+ 和基础依赖：`python -m pip install -r requirements.txt`。
2. 双击 `run.bat`，或者运行 `python server.py`。
3. 在浏览器打开 `http://127.0.0.1:8765`。服务默认只允许本机访问。
4. 选择“添加目录”，输入已有图片目录的完整路径，再选择“授权并扫描”。
5. 扫描进度会显示在页面顶部和任务中心。任务中心可暂停、继续或取消任务。

应用只扫描和索引目录，不会在添加图库时移动或复制图片。支持的文件类型由当前安装的解码器决定，界面会列出扫描和预览格式。

## 调整界面背景

点击左下角齿轮打开“本机状态”，在“界面背景色”中选择浅灰、暖灰、中灰或深色，也可以使用颜色选择器自定义。选择会立即应用并保存在当前浏览器中。图片编辑预览区使用中性灰底色，减少纯黑背景对明暗判断的影响。

## 浏览和筛选

- 选择“全部照片”浏览已索引图片。
- 使用图库目录、拍摄日期、标签、评分筛选；可调整每页图片数量。
- 单击图片打开 `PHOTO DETAILS`。详情窗口可用左右箭头或键盘方向键在当前结果集中切换。
- 鼠标滚轮缩放；拖动图片可平移查看。重置缩放可恢复初始视图。

## 搜索

- 没有语义模型时，搜索文件名、标签、OCR 文字及相关元数据。
- 若已安装 SigLIP2 模型并建立语义索引，搜索框也可按图片内容描述搜索。语义结果可以调节最低相似度；更高门槛会过滤较弱匹配。
- SigLIP2 负责视觉语义匹配，不识别图片里的文字。若要搜索图片中的文字，请在详情右侧“OCR 文本”栏粘贴/录入文字并保存。

## 图片详情与编辑

工具位于预览上方，按选择/裁剪、绘制、变换和导出分组。工具选项从对应图标下方弹出，不会撑开主工具栏；画笔和马赛克均可调节粗细，画笔可选颜色，文字可调字号和颜色：

- **拖动查看**：选中手掌工具后拖动图片。
- **裁剪**：框选区域，查看裁剪框后按“完成裁剪”应用，或按“取消”放弃。
- **画笔与橡皮擦**：选中画笔可展开粗细和颜色面板；橡皮擦只擦除画笔笔迹。
- **马赛克**：涂抹需要遮挡的区域。笔刷大小控制马赛克区域；默认是无色调的像素化效果。勾选“色调”后可额外加选定颜色。
- **文字**：框出文字区域，输入文字，可在工具子面板调整字号与颜色，再按“确定”写入图片或取消。
- **旋转/翻转**：在当前编辑画布中调整方向。
- **撤销**：逐步撤销本次详情窗口里的编辑操作。
- **保存**：选择另存目录与文件名，导出 PNG。原始文件不会被覆盖。

更换到另一张图片前，若当前编辑尚未另存，应用会询问是否放弃更改。

## 重复候选

“重复候选”根据感知哈希寻找近似图片，只提供人工复核线索，不会自动删除文件。打开候选详情可以在候选组内切换；“移入回收站”仍需确认，完成的文件操作可从操作记录撤销。

## 整理与操作记录

详情页的移动、改名和移入回收站会先生成预览，再由用户确认。移动或改名只允许在已添加的图库目录范围内操作。目标文件若已存在，应用会拒绝覆盖。操作记录可删除；删除记录不会删除文件，但会移除该记录对应的撤销入口。

## 移除图库

侧栏目录旁的移除按钮会清除应用中的目录授权、索引记录和关联缓存，不会删除原始目录或其中的图片。若目录正在扫描，先在任务中心暂停或取消扫描。

## 数据位置和备份

默认数据位于 `%LOCALAPPDATA%\LocalImageLibrary`，包括 SQLite 数据库、缩略图缓存和应用回收站。设置中可以调整缩略图缓存上限。页脚“导出数据库备份”用于保存 SQLite 数据库副本；备份不包含图片原文件和可重建缩略图。

## SigLIP2 设置

从 [google/siglip2-base-patch16-224](https://huggingface.co/google/siglip2-base-patch16-224) 下载模型，将完整文件放在项目 `.local-models/siglip2-base-patch16-224/`。安装 `requirements-semantic.txt` 和与你的驱动匹配的 PyTorch 后，在“本机状态”中建立语义索引。GPU 不可用时会尝试 CPU 推理。
